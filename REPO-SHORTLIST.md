# Repo Shortlist

Filtered from the GitHub search to keep only repos worth checking further.

## Use First

### `souravvoid/-rapid-response-ems`
- URL:
  https://github.com/souravvoid/-rapid-response-ems
- Why keep:
  Closest single-repo match to the target.
- Worth stealing:
  incident intake, best-ambulance selection, hospital-bed fallback, driver GPS flow, simple dispatch loop.
- Main caution:
  mostly rule-based and graph-based, not a serious optimization engine.

### `qppd/ambulance-dispatch-management-system`
- URL:
  https://github.com/qppd/ambulance-dispatch-management-system
- Why keep:
  strongest app/product shell.
- Worth stealing:
  multi-role flows, dispatcher dashboard, driver workflow, citizen tracking, audit and analytics, realtime data model.
- Main caution:
  hospital module is not core yet.

### `hackathon-NareshIT/liferoute-ai-smart-emergency-ambulance-routing-system`
- URL:
  https://github.com/hackathon-NareshIT/liferoute-ai-smart-emergency-ambulance-routing-system
- Why keep:
  practical routing-oriented backend with hospitals, ambulances, requests, and OSRM.
- Worth stealing:
  hospital APIs, ambulance location updates, severity scoring scaffolding, route optimization endpoints.
- Main caution:
  demo-grade and pseudo-ML.

### `dhcsousa/hospitopt`
- URL:
  https://github.com/dhcsousa/hospitopt
- Why keep:
  strongest optimization logic and most serious engineering shape.
- Worth stealing:
  ambulance-patient-hospital assignment model, constraints, worker pattern, API/dashboard separation.
- Main caution:
  not a polished public-facing dispatch app.

1. CRITICAL API BUG FIX
   File: src/services/api.js (Line 52)
   
   Problem: Ambulance API was not being called correctly
   - Backend expects: latitude, longitude, radius
   - Frontend was sending: lat, lng, radius
   
   Solution: Updated ambulancesApi.getAvailable() function
   OLD: getAvailable: (lat, lng, radius) => api.get('/api/ambulances/available', 
        { params: { lat, lng, radius } })
   NEW: getAvailable: (lat, lng, radius) => api.get('/api/ambulances/available', 
        { params: { latitude: lat, longitude: lng, radius } })
   
   Impact: This was preventing ambulances from loading. Now FIXED!

USER WORKFLOW:
================================================================================

1. User clicks "Assign" button in DashboardPage
2. AssignmentWizard dialog opens
3. Component automatically loads:
   - Nearby ambulances (GET /api/ambulances/available)
   - Hospital recommendations (GET /api/hospitals/scored/{id})
4. User selects ambulance from list
5. Clicks "Next" → Goes to Step 2
6. User selects hospital from list
7. Clicks "Next" → Goes to Step 3
8. Reviews summary and can add optional notes
9. Can optionally activate Green Corridor
10. Clicks "Create Assignment"
11. Component submits data (POST /api/assignments)
12. On success:
    - Calls onAssignmentCreated callback
    - Closes dialog
    - Resets all state
13. Parent component (DashboardPage) refreshes incident/ambulance data

================================================================================
API ENDPOINTS USED:
================================================================================

1. GET /api/ambulances/available
   Parameters: latitude, longitude, radius
   Returns: List of available ambulances
   Used by: Step 1 - Ambulance Selection

2. GET /api/hospitals/scored/{incidentId}
   Parameters: incidentId (from incident object)
   Returns: Scored hospital recommendations
   Used by: Step 2 - Hospital Selection

3. POST /api/assignments
   Body: { incident_id, ambulance_id, hospital_id, notes, activate_green_corridor }
   Returns: Created assignment object
   Used by: Step 3 - Assignment Submission
